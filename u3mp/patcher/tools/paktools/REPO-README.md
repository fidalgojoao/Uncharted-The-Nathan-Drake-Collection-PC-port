# Uncharted 2 Multiplayer / Co-op (private dev snapshot)

Private working copy of the Uncharted: The Nathan Drake Collection PC port, with the **unreleased
Uncharted 2 multiplayer and co-op work** (snapshot of 26 Oct 2026). It is shared so we can build
and test it together; nothing here is released. The normal port README is in
[PORT-README.md](PORT-README.md).

No game files, executables, logs, screenshots or save data are in this repository. You need your
own Collection dump (1.02 update) as for the public port.

## Multiplayer is opt-in

Nothing changes for single player unless you turn it on:

- The launcher's **Multiplayer** page is hidden unless `UNCHARTED_MULTIPLAYER=1` is set or a file
  named `multiplayer-preview` exists in `analysis\uncharted-user\` (empty file is enough).
- The runtime only goes online when `UNCHARTED_NET_MODE` (host / join) is set; the launcher's
  Host / Join buttons set it and the other `UNCHARTED_NET_*` values for you.

## What works

- **LAN transport** (`gow3_pc/src/runtime_net.c`): U2's own packet protocol survived in the PS4
  build, only the sockets/session layer was gone; it now runs over TCP (default port 27000).
- **Lobby flow**: launcher Host/Join -> U2's own Custom Game lobby. Joiners see "Waiting for Party
  Leader...". The host changes Game Type and Map, Start Game restarts both games into the match;
  after the round, results for 12 s, then everyone is back in the lobby.
- **Remote animation**: the other players animate correctly (snapshot tail fix, 0 failures in
  the suite).
- **Tony's PS3 spawn points** (PR #231) drive the classic maps: Village, Plaza, Sanctuary, Ice
  Cave, Lost City, Train Wreck, Temple, plus The Fort with its own spawners
  (`gow3_pc/src/runtime_uc2mp_netmaps.c`, catalogue generated by
  `tools/uc2mp_generate_spawn_catalog.py` from your own PS3 files).
- The launcher lists 9 games: Village co-op, Fort deathmatch, 7 classic deathmatches.
- **Automated suite 10/10 PASS**: two games on one PC, scripted, silent. Lobby loop, Village
  co-op (114), Fort DM (124), Village (25), Plaza (30), Sanctuary (0), Ice Cave (5), Lost City
  (10), Train Wreck (15), Temple (20). Each run: both games reach the match, ~2 min of play with
  0 faults and 0 bind poses, round end -> results.

## What is left

1. **Co-op enemies**: the joiner sees the host's soldiers move and shoot and can kill one, but
   the host then crashes awarding the co-op points for that kill. A fix is written, not tested.
2. **Party names** in the lobby/scoreboard.
3. **Overlapping lobby rows**: Map and Game Type are drawn on one line (both still work).
4. **Objective modes** (Plunder, King of the Hill, Turf War, Chain Reaction, Elimination) on the
   classic maps: untested / not wired.
5. **Main-menu Multiplayer entry** in the game itself (today it starts from the launcher).
6. **A real two-PC test** (all tests so far are two instances on one PC over 127.0.0.1).

## Build

Same as the port (see `gow3_pc/packaging/windows/README.md`):

1. Clone with submodules: `git clone --recursive <this repo>` (or `git submodule update --init --recursive`).
2. Install MSYS2 and the CLANG64 packages listed in `gow3_pc/packaging/windows/README.md`.
3. In the MSYS2 CLANG64 shell: `gow3_pc/build.sh` -> `gow3_pc/out/gow3-probe.exe`.
4. Optional: `tools/package_windows.sh` for a player package.

The GitHub Actions workflow (`.github/workflows/build-windows.yml`) is set to **manual runs only**
here (Actions -> Build Windows -> Run workflow) so pushes do not burn private Actions minutes.
`tools/pkgtool/PkgTool.exe` and its DLL are not included (no binaries); take them from a port
release if you need the update installer.

## Knobs

Launcher/runtime (set by the launcher's Multiplayer page; usable by hand):

| Variable | Meaning |
|---|---|
| `UNCHARTED_MULTIPLAYER=1` | show the launcher's Multiplayer page |
| `UNCHARTED_NET_MODE` | `host` or `join` |
| `UNCHARTED_NET_ADDRESS` | `host:port`, e.g. `127.0.0.1:27000` |
| `UNCHARTED_NET_GAME` | net game id (114 Village co-op, 124 Fort DM, 25/30/0/5/10/15/20 classic DMs) |
| `UNCHARTED_NET_TITLE` | game title shown in the lobby |
| `UNCHARTED_NET_NAME`, `UNCHARTED_NET_SKIN` | player name and character (e.g. `hero-default`, `mp-hero-elena`) |
| `UNCHARTED_NET_LOBBY=0` | skip the lobby, start the match directly |

Developer knobs (runtime, off by default; details in the notes and the source):

- `GOW3_NET_HOST` / `GOW3_NET_JOIN` / `GOW3_NET_ID` / `GOW3_NET_NAME` / `GOW3_NET_SKIN` /
  `GOW3_NET_GAME` / `GOW3_NET_TITLE`: low-level equivalents; `GOW3_NET_TRACE=1` logs packets.
- `GOW3_COOP_BOOT`, `GOW3_COOP_CMD` (console command file, e.g. `mpmenu endgame 4`),
  `GOW3_COOP_MAP`, `GOW3_COOP_SOLO`.
- `GOW3_COOP_MP_*`: `LEVELS`, `TEAMS`, `TWINS`, `SKIN`, `SPAWNS`, `SPAWN_FILE`, `SPAWN_DUEL`,
  `SPAWN_PROBE`, `MENU_GUARD`, `RESULTS_SECONDS`, `CLASSIC`, `OBJECTS`, `OBJ_ALIAS`, `TANK`,
  `KEEP_FG_HIDE`, `KEEP_MASK_BUG`.
- `GOW3_COOP_NETANIM`, `GOW3_COOP_NETANIM_ANIMS`, `GOW3_COOP_NETANIM_DEPTH`,
  `GOW3_COOP_NETANIM_PAD`: remote animation.
- `GOW3_COOP_NPC`, `GOW3_COOP_NPC_GRENADES`, `GOW3_COOP_NPC_SPAWN_MS`: co-op enemies (work in progress).

## Running the suite (two instances on one PC)

```bash
bash multiplayer/scripts/an/suite.sh <path to gow3-probe.exe> <tag prefix>
python -I multiplayer/scripts/an/suite_report.py <tag prefix>
```

Each run uses `pairrun.py`: host and joiner as two windows (left/right half), silent, no input
devices, over 127.0.0.1:27000; the joiner uses `UNCHARTED_INSTANCE=2` for its own user folder.
