**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 online (multiplayer build v7.73)

- **Profile changes are no longer undone when you leave and re-enter multiplayer.** Re-entering multiplayer reloaded the profile as it was at sign-in, which reset Hat Stats, DLC and any loadout or setting changed since, and then saved that old copy over the new one. The profile you last saved is now the one loaded.
- **"No connection found" after signing in should be gone.** The game asked the community DNS server for the Uncharted 3 server's address only once; when that one answer was lost, the whole session stayed offline until you signed in again. It now asks up to five times, and asks again at the next sign-in if it failed. boot.log shows each retry.

Still not working: kicking a player and promoting a party leader.
