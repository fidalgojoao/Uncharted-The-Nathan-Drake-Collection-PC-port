**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Multiplayer import

- **The US Game of the Year edition (BCUS99086) works too**, next to the EU one (BCES01670). Both have the same 1.19 code and the same game files apart from the speech languages; the import uses English speech, which both have.
- **The decrypted 1.19 EBOOT is found under any name** (for example `EBOOT-1.19.elf`), as long as it is the 1.19 one.
- The import's messages and the README name both regions.
