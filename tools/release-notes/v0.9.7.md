**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x:** press **UPDATE** next to PLAY. Your multiplayer import updates itself in the background; only the changed maps are rebuilt. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Maps

- **Airstrip is now exact.** All three Airstrip map files now come out identical to the reference build. That means its later fixes finally apply: the wall emblems and the duplicate control tower / excess wall fix.
- **Two more maps are now exact:** the Oasis stage (oasis-multi-stage) and the London library co-op area (coop-ldn-library-inner).
- **Recovered fixes restored.** A batch of later map fixes (water layer, blockers, detail textures, level info) had been lost. They are back in the import and apply to every map that is rebuilt exactly.

## Coming

- More maps are still being matched to the reference build. Each one that matches will arrive as a small update; press UPDATE when the launcher offers it.
