**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online (multiplayer build v7.75)

- **Invites from other players now show up.** When an invite was waiting, the Uncharted 3 server's answer to "which invites do I have?" was refused by the PC version: the server labels that answer one byte short, and the PC trusted the label where the PS3 game reads whole blocks. The PC now reads it as the PS3 game does.
- **Fewer "No connection found" after signing in.** The server address is now looked up by the sign-in itself, with real timeouts and up to five tries; before, the lookup could stall for good while the game was busy. If the server part of the sign-in still fails, it is tried again every 15 seconds (up to 8 times) while you stay signed in to RPCN, so Play Online works again without restarting the game.
- **boot.log says more when the server cannot be reached**, including when the address found looks like Amazon's own (a router, provider or antivirus answering DNS questions instead of the community DNS).

Still not working: kicking a player and promoting a party leader.
