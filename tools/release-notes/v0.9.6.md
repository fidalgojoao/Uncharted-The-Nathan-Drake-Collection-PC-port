**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x:** press **UPDATE** next to PLAY. Your multiplayer import updates itself in the background. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Import fixes (from players' logs)

- **"Game running: stop it first" with the game closed.** Four steps (map colours, London fade, VRAM gap, wall colours) mistook the **launcher** for the game, because both have "Uncharted" in their name. So they refused to run in every import started from the launcher. They now look for the game itself.
- **Lab props failing after the game data arrived.** The import kept PS3 extracts from earlier attempts, including a Lab extract made before the Lab data was there. It now rebuilds those caches whenever your PS3 files or the game data change.
- **Game of the Year disc:** the Shade Arena fix now accepts the GOTY version of the Gompa map.

## Known

- The **Airstrip** wall emblems and the duplicate wall fix still don't apply on any import. They need two Airstrip map files that aren't rebuilt exactly yet. Airstrip is fully playable without them, and they'll arrive in an update.
