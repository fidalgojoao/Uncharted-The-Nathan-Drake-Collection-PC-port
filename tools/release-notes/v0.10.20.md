**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (the Uncharted 3 multiplayer image is relinked in a few seconds). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online (multiplayer build v7.66)

Fixes from the first test of 0.10.19, where neither saved loadouts nor game invites worked:

- **Saving your profile now uses the same signed request as the PS3 game.** The server refused 0.10.19's unsigned upload (HTTP 403), so loadouts still reset. boot.log shows "profile saved to the server ..." with the result.
- **Game messages now reach RPCS3/PS3 players, and theirs reach you.** The PC version labelled its messages with the wrong message type, so every invite notice, join request and join reply was dropped on both sides.
- **Invites and friend status from RPCS3/PS3 players are no longer thrown away.** Their game data carries a newer network version (0x74) than the one the PC version expected (0x64). Any Uncharted 3 network version is now accepted, and the PC version uses your friend's.
- **A party that cannot take your join request now says so at once** instead of after a 20-second wait.
- **Accepting an invite while your friend list refreshes keeps the invite**, so you can accept it again.

Still not working: kicking a player and promoting a party leader (the game has both actions, but the menu that calls them is not restored yet).

This is new: if loadouts do not stay saved or invites do not arrive, please send the boot.log (and RPCS3.log if the other player uses RPCS3).
