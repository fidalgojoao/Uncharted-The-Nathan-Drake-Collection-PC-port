**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Launcher

- **Guided multiplayer setup:** the Uncharted 3 Multiplayer tab now shows the setup as four numbered steps (PS3 folders, decrypted EBOOT, data folder, Import). The space saver has its own Storage box after them.
- **One DNS box:** the RPCN DNS Server box is also used by the multiplayer import.
- **Shorter game cards** reading "Uncharted 1/2/3", level with the title.
- **Maximize and restore** no longer leave a black background or a doubled picture.
- Boxes and fields share the same see-through frosted look; content scrolling out of view now ends in rounded corners.
