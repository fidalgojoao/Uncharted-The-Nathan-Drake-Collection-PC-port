**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x:** press **UPDATE** next to PLAY. Your multiplayer import updates itself in the background, so there's no need to import again.
**New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Fixes

- **Game of the Year disc, no separate DLC installed:** the import now takes the DLC maps from the GOTY disc (`goty-dlc.psarc`). Before, every map conversion was skipped.
- **No more crash at boot after an incomplete import.** An import missing files could stop Uncharted 3 at startup with *"Module file ... player-settings.bin size exceeds the reserved memory size"*.
  - Such an import is now marked failed, with the reason, and Uncharted 3 starts **without** multiplayer instead of crashing.
  - An import already in that state is recognized too: after this update, the game starts normally.
- **The import checks your PS3 files before it starts.** If something it needs is missing or a different version, it stops right away and says what to do. This covers:
  - the DLC map packs;
  - the game data folder `BCES01670DATA2` (written by Uncharted 3 when it goes online in RPCS3), with its network table and Lab maps.

## Maps

- 4 more maps are rebuilt byte-identical: Fort co-op cistern, Monastery co-op stage, Ruins stage, Train Wreck stage.

## Requirements reminder

- **PS4:** CUSA02320 with update 1.02.
- **PS3:** Uncharted 3 (BCES01670) with update 1.19, the DLC map packs (or the GOTY disc), and the game data folder `BCES01670DATA2`.
