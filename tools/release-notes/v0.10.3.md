**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. The multiplayer image is relinked in a few seconds; nothing is imported again. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Fix

- **Co-op adventure crash at the end of London chapter 2** ("ASSERTION: m_npcCount < 9"). The PS4 game stopped when a ninth enemy appeared, a leftover debug check; the enemy list itself holds 32, and the PS3 game (where co-op adventures were made) has no such check. The check is skipped now.
