**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online (multiplayer build v7.90)

- **Online matches with several players are being worked on.** Known: a freeze some minutes into a match, the player name floating away from the character, only the party leader can throw grenades, and lag. This build records what is needed to fix them:
  - if the game freezes, it writes `analysis\big3-ps4_Shipping\u3mp-freeze.txt` (what the network code was doing);
  - every 30 seconds in a match, boot.log gets a line per player with the connection quality (round trip, packets per second, clock sync).
  Please send your boot.log (and u3mp-freeze.txt if there is one) after an online match.

## Launcher

- The window title of the launcher and of the game now also shows the imported multiplayer build ("Imported v7.90").
- **No old copies are kept on your PC:** an import copy left behind by an update (a file was in use at that moment) is deleted at the next import or update, and an update that is not applied deletes its half-made copy too. Old multiplayer builds are no longer shipped, and this update removes the ones you have.

Still not working: the Invites tab stays empty (join through the friend list instead).
