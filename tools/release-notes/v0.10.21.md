**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer visuals (overlay recipe 1.10.2)

Thanks to 33martyr for both fixes:

- **Yeti mask:** the teeth now have proper shading (their surface data was missing and is rebuilt from the PS3 model).
- **Outdoor Jacket A:** its colour map is restored and its surface shading rebuilt.

## Uncharted 3 online (multiplayer build v7.71)

- **Custom loadouts, characters and the rest of your online profile are now saved on the server.** The PC version sent its sign-in to the Uncharted 3 server unencrypted, where the PS3 game encrypts it. The server never accepted that sign-in, so it refused every profile save ("403 Forbidden"). The sign-in is now sent exactly as the PS3 game does, and the save request matches the PS3 game's byte for byte. boot.log shows "server sign-in accepted" and "profile saved to the server ...".
- **Invites that arrive while the invite list is busy are no longer missed.** The notice is kept and the list is fetched as soon as it is free.
- **More detail in boot.log** for invites: the server's answer to each invite-list, who each listed invite is from, each invite notice, and what the Invites tab shows.

Still not working: kicking a player and promoting a party leader.

Testing tip: two accounts on one PC (for example the PC game and RPCS3) show the wrong sender on invites. Test invites between two PCs.
