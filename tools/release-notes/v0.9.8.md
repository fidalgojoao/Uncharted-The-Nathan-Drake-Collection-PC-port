**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x:** press **UPDATE** next to PLAY. Your multiplayer import updates itself in the background. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Fixes (from a player's log)

- **Updating to 0.9.7 left Airstrip half-done.** An update never replaced a map you already had unless the new build was exact. So players who updated kept their old Airstrip maps, and the wall emblems, orange wall and excess wall fixes failed. Updates now rebuild a map when yours is from an older version, and those four Airstrip steps install over what an earlier import left behind.
- **Steps that never ran again.** When a step's files already matched the reference, the import didn't remember which files they were. If a later update changed them, the step was skipped. The import now remembers them and runs the step again when needed. For example, the Airstrip emblem settings now apply after an update.

Fresh imports were not affected. If your last import or update reported failed Airstrip steps, press UPDATE; there's no need to start over.
