**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Multiplayer with the Lab maps, straight from the community server

- The import now accepts the community server's **current** network table (`net18.bin`). The multiplayer menus are built with the server's up-to-date playlist and mode values.
- With the **Community server DNS** set on the Multiplayer tab, the import downloads the game data from the server, **including the Lab maps**. You don't need to go online in RPCS3 first.
- Tested: every menu and module file builds from the server's version. The files the update doesn't touch still come out byte-identical.
- If the server's table changes again in the future, the import stops safely (Uncharted 3 still starts, without multiplayer) and the log shows the new version, so it can be added.

## Smaller fixes

- The store's upgrade list is optional in the download. The import doesn't use it, and it no longer stops the download.
- When an update can't start, the import now says why.
