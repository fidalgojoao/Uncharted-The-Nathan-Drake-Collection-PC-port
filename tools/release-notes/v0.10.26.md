**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online (multiplayer build v7.81)

- **Leaderboards work online.** Community > Leaderboards now asks the Uncharted 3 server (as the PS3 game does), and your match scores are sent to it. Before, the PC version asked an old server of its own that is not running, so the boards stayed empty.
- **The PC version reports itself to the server like the PS3 game** (the regular "heartbeat": signed in, in the menus or matchmaking).
- **Long names in "You received an invite from ..."**: a name that does not fit is shown as "Party Invite: <name>", so it is never cut off.
- **Party rank badges** no longer stop loading after you open someone's Statistics.
- Everything from 0.10.25 (kick / promote / report, other players' stats, party matchmaking) is included and still waiting for its first full test: please send your boot.log if something does not work.

Still not working: the Invites tab stays empty (join through the friend list instead).
