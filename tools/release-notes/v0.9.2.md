**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.
**Already on an earlier build of this launcher:** press **UPDATE** next to PLAY. (Replaces 0.9.1, which shipped two small textures copied from the game; they are now made on your PC like everything else.)

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer (beta)

- **MULTIPLAYER tab: Import.**
  - It converts the multiplayer files from your own PS3 Uncharted 3 (disc or ISO, plus RPCS3's `dev_hdd0/game`: update 1.19, game data, DLC map packs) and this PS4 Collection.
  - A fresh import takes about an hour on a modern 8-core PC.
  - It skips the files the game never loads and runs on all but 2 CPU cores.
- **Online play:** sign in with your RPCN account in the game's RPCN page (L2 in the front end).
- **Updates without re-importing:**
  - After a launcher update, the Multiplayer tab brings your import up to date by itself, at low priority.
  - A new multiplayer build only relinks the game file, which takes seconds.
  - New or improved conversion steps rebuild the import in a second folder, and you can keep playing on your current files meanwhile. The update is swapped in when it is complete and no worse than what you have.
  - Without room for a second folder (about 11 GB), it updates in place.
- **Maps:** the 8 sky maps and the 7 Borneo (co-op) water maps are now byte-identical to the reference build. In total, 99.3% of the files the game loads are identical.

## Known issues

This is a beta: please report problems as GitHub issues, with the import log (Multiplayer tab → Open import log).

- Some maps are still close rebuilds rather than byte-identical. They play the same; the remaining ones are listed in the recipe's GAPS.md.
- The Airstrip wall emblems are not restored on a fresh import yet.
