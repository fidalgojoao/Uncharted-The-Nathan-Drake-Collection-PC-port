**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (the Uncharted 3 multiplayer image is relinked in a few seconds). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online (multiplayer build v7.64)

- **Your online profile is saved to the server.** Loadouts, characters, boosters, progress and clan tag used to reset at every sign-in, because the profile was downloaded but never uploaded. It is now uploaded after every match or change, as on PS3, so it stays between sessions and is the same on PS3/RPCS3. The upload is checked before it is sent, it is never sent when the sign-in's download failed, and the server's copy is backed up on your PC first (`u3-lan-mp-online-<account>-server-backup.v1`). boot.log shows "profile saved to the server ...".
- **Invites arrive more reliably.** One failed connection to the invite server no longer switches it off for the rest of the session; every invite tries it again.
- **Accepting an invite no longer gets stuck.** If the inviter's party was busy (being created or changing owner) when you accepted, the request was never answered and the "Joining Party..." wait ran out. It is now answered as soon as the party is ready.
- Includes the 0.10.18 fix for the crash while characters load.

This is new: if your loadouts do not stay saved, or boot.log reports a failed save, please send the boot.log.
