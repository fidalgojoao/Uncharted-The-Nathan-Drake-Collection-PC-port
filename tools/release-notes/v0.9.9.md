**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x:** press **UPDATE** next to PLAY. Your multiplayer import updates itself in the background. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Fixes (from players' logs)

- **Update 1.02 in its own folder.** With the PS4 update kept in a separate folder (for example `CUSA02320-patch` next to the game), the import read only the base 1.00 files, so most multiplayer steps failed: menus, net data, the HUD and the Chateau stage. The import now reads your game with the update laid over it, exactly as the game sees it. Both setups work: the update merged into the game folder, or in its own folder. Nothing is copied when both are on the same drive.
- **Non-English Windows.** The check that waits for the game to close crashed on Windows in other languages (Spanish, for example), so the map colours, London fade and airport steps failed. Fixed.

If your last import reported failed steps, press UPDATE; there's no need to start over.
