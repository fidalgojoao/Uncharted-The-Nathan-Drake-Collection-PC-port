**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online (multiplayer build v7.91)

- **Every player can throw grenades again**, not only the party leader or match host. The game blocks throws for the first 3 seconds of a round. The other players got the round start in the host's time, and with their clock behind the host's, that block never ended. Now the round start is checked against each player's own clock, and the clocks are synced again at every round start (Custom Game, matchmaking and LAN).
- boot.log now shows each round start, both clocks and every clock sync. Please send your boot.log after an online match, and `u3mp-freeze.txt` if the game froze.

## Launcher

- **New option on the Multiplayer tab: "Keep only the PS3 files updates need (saves space)".** It's off by default and only saves disk space; it changes nothing in the game. When it's on, the launcher keeps just the PS3 Uncharted 3 files the import uses (about 14 GB of about 51 GB) in the multiplayer data folder. You can then delete your PS3 Uncharted 3 folders and updates still work. On the same drive the files are hard links (no extra space until you delete the PS3 folders); on another drive they are copied and checked.
- **Import fix:** if you imported once without the decrypted PS3 EBOOT.elf and added it later, 93 props (crates, luggage, Lab boxes, a Fort gate) stayed broken. They are now converted at the next import. This update rebuilds the multiplayer files in the background; only the steps that changed run again.
