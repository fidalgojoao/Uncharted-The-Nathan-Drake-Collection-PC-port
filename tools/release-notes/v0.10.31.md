**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY. **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Launcher

- **UPDATE no longer fails with "Access is denied ... libcrypto-3.dll"** when a multiplayer import or update is running in the background. The import uses the launcher's own Python, which the update has to replace, and Windows does not allow that while the files are in use (the previous version was kept, nothing was lost). The launcher now tells you to wait until the import has finished, then press UPDATE again.

Everything from 0.10.30 is included (multiplayer build v7.90 with the match diagnostics: please send your boot.log, and u3mp-freeze.txt if the game froze, after an online match).

Still not working: the Invites tab stays empty (join through the friend list instead).
